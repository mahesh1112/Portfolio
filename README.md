# Mahesh Shriram — AI/ML Portfolio

A responsive, static portfolio website focused on AI/ML research, LLM fine-tuning, retrieval, evaluation, and agentic systems.

## Project structure

```text
mahesh-ai-portfolio/
├── index.html                 # Website entry point
├── styles.css                 # Styles and responsive layout
├── public/
│   └── Mahesh_Resume.pdf      # Downloadable resume
├── README.md
└── .gitignore
```

## Run locally

No Node.js, npm, build step, or framework is required. Open `index.html` in a browser, or use VS Code's Live Server extension.

## Publish using GitHub Pages

1. Push these files to the root of your GitHub repository.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your branch (usually `main`) and the `/(root)` folder, then save.
5. Wait for GitHub Pages to publish the site.

The expected URL for a repository named `mahesh-ai-portfolio` is `https://mahesh1112.github.io/mahesh-ai-portfolio/`. If you use a different repository name, update the URL accordingly.

## Customization

- Edit page content and project cards in `index.html`.
- Edit colors, typography, and layout in `styles.css`.
- Replace `public/Mahesh_Resume.pdf` with your latest resume while keeping the same filename, or update the resume link in `index.html`.

All project links are included only where a public repository is available. The multi-agent bug-fixing system is presented as a work case study without a public repository link.
